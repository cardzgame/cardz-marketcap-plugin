# CARDZ plugin privacy

Operator: Jackz Intelligent Technology Co., Ltd., Japan. Public brand: CARDZ. Contact: alex@jackz.ai.

The adapter sends only the selected tool's card search text, public card ID, game, display language, ranking scope, history window or result limit to https://mcp.cardz.game/mcp over HTTPS. Do not enter personal information into card search fields.

It does not read conversation history, user profiles, player accounts, payments, private holdings or files. It does not store queries, write local files or log request/response content. It requires no credentials and shares no credentials with CARDZ.

The service is operated on Cloudflare. Network infrastructure processes normal request metadata such as the connecting IP and applies rate limiting. Dify also processes the tool inputs and outputs under the deployment's own policies. The adapter creates no query-history database.

Service privacy and terms: https://mcp.cardz.game/privacy and https://mcp.cardz.game/terms . Cloudflare privacy: https://www.cloudflare.com/privacypolicy/ . Dify privacy: https://dify.ai/privacy .

Contact alex@jackz.ai for questions about this plugin's data handling.
